# Agentic CAD Intelligence Platform

Welcome to the **Hybrid Agentic CAD Builder**. This system blends the creative reasoning of Large Language Models (LLMs) with the strict, deterministic accuracy of traditional mechanical CAD engines (CadQuery).

## Features
- **Design Intelligence Layer:** Validates mechanical parameters (e.g. minimum gear teeth, shaft aspect ratios) to ensure physical manufacturability, warning you before proceeding.
- **Semantic Memory:** Caches past successful designs to a local JSON memory bank. If you request a previously generated part, it fetches it instantly, bypassing the AI.
- **Natural Language Parsing:** Say "I need a shaft with a gear on it," and the AI determines exactly which primitives, dimensions, and assembly instructions are required.
- **Deterministic Geometry:** Your B-Rep files are generated by CadQuery, guaranteeing engineering-grade topology every time.

## Prerequisites
- Docker & Docker Compose
- An OpenAI API Key (for the LLM Planning Layer)

## Getting Started

### 1. Set Your API Key
The system uses GPT-4o (via OpenAI) to extract strict CAD parameters. You must export your API key before launching the system.
```bash
# On Linux / macOS / WSL
export OPENAI_API_KEY="sk-your-api-key"

# On Windows PowerShell
$env:OPENAI_API_KEY="sk-your-api-key"
```

### 2. Build and Run the Environment
The project now runs as a multi-container Docker environment. The core CAD engine and the interactive Streamlit GUI are run in parallel.
```bash
# To start the Streamlit GUI and the CLI services:
docker-compose up --build
```
*Note: The `agentic-gui` service will host the web interface at `http://localhost:8501`. The `gear-generator` service will still drop you into an interactive CLI prompt if you run it explicitly (`docker-compose run --rm -it gear-generator python gear_engineering/main_pipeline.py`).*

### 3. Usage Examples
When prompted, try typing natural language requests:
- *"Create a shaft of length 100mm with a diameter of 15mm, and mount a module 2 gear with 25 teeth on it."*
- *"I need a heavy duty flange with 10mm thickness."*
- *"Generate a bearing with 20mm inner diameter and 40mm outer diameter."*

The AI will parse your request, run it through the Design Intelligence validation (warning you if parameters are unsafe), generate the geometry, and export the file.

### 4. Where is my CAD file?
The generated mechanical assembly is saved directly to your host machine in the `outputs/` directory as `agentic_assembly_output.step`. Additionally, individual `.stl` files for gears, shafts, bearings, and the housing are exported there for the GUI to render. Open these files in FreeCAD, Fusion360, or any STEP/STL viewer.

## Architecture Notes
- **`core/llm_client.py`:** Holds the Pydantic schemas and talks to OpenAI.
- **`core/design_intelligence.py`:** Enforces engineering rules.
- **`core/memory.py`:** Manages the `memory_db.json` local cache.
- **`components/` & `assembly/`:** The unchanged deterministic geometry core.
